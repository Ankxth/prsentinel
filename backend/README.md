# backend

FastAPI service served with uvicorn.

## Run it

```bash
cd backend
python -m venv .venv
source .venv/bin/activate          # Windows Git Bash: source .venv/Scripts/activate
pip install -r requirements.txt
cp .env.example .env               # then fill in what you need
uvicorn app.main:app --reload      # http://127.0.0.1:8000/health
python -m pytest -q
```

## Database migrations (Alembic)

Needs `DATABASE_URL` in `backend/.env`.

```bash
alembic upgrade head                            # apply all pending migrations
alembic revision --autogenerate -m "add repos"  # draft a migration after changing models
alembic downgrade -1                            # undo the last one
```

Read every autogenerated migration before applying it. Models go in `app/db/models/`
(import each one in `app/db/models/__init__.py`). Use Supabase's **Session pooler** connection
string (it works over IPv4; the Direct string is IPv6-only by default).

On Render the start command becomes
`alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port $PORT`.

On Render (without migrations yet) the start command is
`uvicorn app.main:app --host 0.0.0.0 --port $PORT`.

## Layout

```
app/
  main.py        create_app(): builds the FastAPI app
  core/          settings (config.py); later auth, logging, rate limits
  api/           one router file per area (health.py so far)
  db/            base.py, session.py, models/ (one file per area)
migrations/      Alembic: env.py and versions/
  services/      (later) context engine, LLM router, classifier, runs
  agents/        (later) vulnerability proof agent
tests/
```

See `../docs/context.md` for how the pieces fit together.
